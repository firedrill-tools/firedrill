# Reusable Tool packs

> Generated by `pnpm registry:write`. Do not edit this file by hand.

A Tool pack adds a reusable action surface to a Firedrill world. This catalog helps humans and coding agents discover packs; it does not install or activate them. A pack runs only after it is installed and explicitly selected in `firedrill.json`. Firedrill validates the exact installed artifact and can then run it offline.

Package-manager availability depends on each pack's release status. Follow the linked pack documentation instead of assuming every catalog entry has been published.
